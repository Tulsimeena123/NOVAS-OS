# 🚀 NOVAS OS

### A Modern Productivity Web Application

Manage your Notes, Tasks and Daily Productivity in one place.

Built with **React + Tailwind CSS + Appwrite**

</div>

---

## ✨ Features

### 🔐 Authentication
- User Signup
- User Login
- Secure Logout

### 📝 Notes
- Create Notes
- Search Notes
- Delete Notes
- Live Appwrite Database

### ✅ Tasks
- Add Tasks
- Complete / Undo Tasks
- Delete Tasks
- Live Task Status

### 📊 Dashboard
- Live Notes Counter
- Live Tasks Counter
- Completed Tasks Counter
- Pending Tasks Counter
- Recent Notes
- Today's Tasks

### 👤 Profile
- User Name
- Email
- User ID
- Join Date
- Logout

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Tulsimeena123/NOVAS-OS.git
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```
