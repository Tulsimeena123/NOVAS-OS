# 🚀 NOVAS OS

> A modern productivity web application built with **React.js**, **Tailwind CSS**, and **Appwrite**.

Manage your **Notes**, **Tasks**, and **Daily Productivity** in one beautiful dashboard.

# ✨ Features

## 🔐 Authentication

- User Signup
- User Login
- Secure Logout
- Session Management using Appwrite

---

## 📝 Notes

- Create Notes
- Search Notes
- Delete Notes
- Live Database

---

## ✅ Tasks

- Add Tasks
- Complete / Undo Tasks
- Delete Tasks
- Live Task Status

---

## 📊 Dashboard

- Total Notes
- Total Tasks
- Completed Tasks
- Pending Tasks
- Recent Notes
- Today's Tasks

---

## 👤 User Profile

- User Name
- Email
- User ID
- Join Date
- Logout

---

# 🛠 Tech Stack

## Frontend

- React.js
- Tailwind CSS
- React Router DOM
- Lucide React
- Vite

## Backend

- Appwrite Authentication
- Appwrite Database
- Appwrite TablesDB

## Deployment

- Vercel

